# Natraj Mobile & Electronics

Dealer finance operations and application management platform.

## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Demo login accounts

Dealer and admin credentials are configured in `.env`. Copy `.env.example` when creating another environment. The login page identifies the account role and redirects to the matching dashboard.

Variables prefixed with `VITE_` are included in the browser bundle. These demo credentials must not be used as production secrets; production authentication requires a backend identity service.
